# Combine glossary sources

Combines the rOpenSci and Weblate glossaries into a single, standardised
glossary data frame.

## Usage

``` r
combine_glossaries(ropensci_glossary, weblate_glossary)
```

## Arguments

- ropensci_glossary:

  A standardised rOpenSci glossary data frame.

- weblate_glossary:

  A standardised Weblate glossary data frame.

## Value

A combined glossary data frame.
